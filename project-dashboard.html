Architecture

Core Loop

main.cpp owns the game loop: splash → input → update (player, level, run manager, juice, artifacts, NPCs, camera) → draw (world space → screen space) → HUD → display. Fixed 60 FPS with dt clamping.

State machine: GameState::Playing | GameState::Won + hub open/closed flag.

Level Pipeline

TileLoader parses assets/levels/level.txt → populates LevelData which owns 8 platform managers. Each manager handles its own update/draw/resolve. World height derived from file — no hardcoded WORLD_H.

Artifact System

Up to 3 equipped artifacts merge into ActiveMods: multipliers take highest (furthest from 1.0), bools OR together. Cosmetic slots (hat, boots, cape, aura, eyes, wings) rendered separately via drawCosmetics().

Save & Progression

Binary save.dat via SaveData struct: coins, best time, artifact owned/equipped bitmasks, discovery bitmask (uint16_t), achievement completed/claimed bitmasks, eye cosmetics. Loaded once at startup, saved on hub interactions & run end.

Hub & Meta

E Interact with NPC
Escape Close panel
R Restart run

Rope vs Ladder: Ropes are slower but launch you sideways if you jump off holding a direction. Ladders are fast and purely vertical.

Dash: 0.13s duration, 0.22s cooldown. Glass Dash artifact = 1 dash per run. Dash cooldown/duration affected by artifacts.

Hub NPCs (5)

Merchant Shop

Buy cosmetic artifacts with coins. Grid layout, cursor navigation, price display, affordability check.

Tailor Cosmetics

Equip/unequip owned cosmetics across 6 slots (hat, boots, cape, aura, eyes, wings). Shows equipped loadout + collection.

Chronicler Time Keeper

Displays best run time (pure, no artifacts). Achievement claim button (★ New! indicator).

Seer Lore

Tarot card lore for each of the 22 sections. Scrollable, section-by-section.

Sage Wise Man

Animated platform encyclopedia. Unlocks entries as you discover platform types (via DiscoveryTracker). PlatformDemo renders live previews.

Build & Run

Quick Start

./rebuild.sh

Cleans build, configures with CMake, builds in parallel, clears save data.

Manual

cmake -B build -G "MinGW Makefiles"
cmake --build build --parallel

Executable at build/ArcaneJourney.exe. Assets auto-copied via POST_BUILD.

Requirements

  • MSYS2 UCRT64 with mingw-w64-x86_64-cmake, mingw-w64-x86_64-gcc
  • CMake ≥ 3.16
  • Git (for FetchContent)
